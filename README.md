# Portfólio DSM

Portfólio pessoal desenvolvido como atividade acadêmica da disciplina de Desenvolvimento de Software Multiplataforma (DSM), sob orientação do professor Jean Carlos.

## Sobre o projeto

Este repositório apresenta um site pessoal com o objetivo de divulgar meu perfil acadêmico, interesses, formação e experiências relacionadas à área de tecnologia. A ideia do projeto é criar uma página profissional simples, visualmente organizada e funcional para apresentar quem sou, o que estudo e para quais áreas tenho interesse.

## Objetivo

- Apresentar minhas informações pessoais e acadêmicas;
- Demonstrar meu interesse por desenvolvimento de software;
- Mostrar meus projetos acadêmicos e pessoais;
- Exibir minhas áreas de estudo e contato profissional.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git e GitHub
- Design responsivo

## Estrutura do projeto

```text
portifolio-dsm1/
├── index.html          # Página principal do portfólio
├── style.css           # Estilos e layout do site
├── foto/               # Arquivos de imagem do perfil
├── README.md           # Documentação do projeto
└── ...
```

## Funcionalidades

- Apresentação pessoal com foto e descrição;
- Seção "Sobre mim" com informações acadêmicas e objetivos;
- Área de interesses e tecnologias que estudo;
- Destaque para projetos acadêmicos e pessoais;
- Informações de formação e contato.

## Como visualizar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/luanhba/portifolio-dsm1.git
```

2. Acesse a pasta do projeto:

```bash
cd portifolio-dsm1
```

3. Abra o arquivo `index.html` no navegador, ou utilize uma extensão como Live Server no VS Code para visualizar melhor a página.
